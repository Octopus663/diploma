# Пілотний прогін у хмарному середовищі (НЕ для диплому)

Перевірка конвеєра `run.sh → parse.py → plots.py → economics.py` у хмарному контейнері розробки
(хост 4 CPU, k6 на тому самому хості, 1 повтор, 20 s, VU 10/50/150, тестові образи замість робочого Dockerfile).
Прогін перервався перезапуском контейнера: немає FrankenPHP/mixed.

Абсолютні числа невалідні. CPU застосунку ~75% на всіх рівнях: застосунок не вибирав ліміт 1 CPU, бо k6 і БД
конкурували за ядра хоста. Для диплому використовуйте прогін на власній машині за `docs/methodology.md`.
Графіки не комітились; відтворюються `python3 analysis/plots.py analysis/results/cloud-sample`.
